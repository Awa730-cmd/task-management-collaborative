# Listes de tâches collaboratives : base pédagogique

Ce dossier contient **uniquement des indications de conception et de réalisation**. Il ne contient ni projet Django, ni modèles, vues, routes, formulaires, base de données ou actions sur les tâches opérationnelles.

Commencez par [SPECIFICATION.md](SPECIFICATION.md), puis utilisez les gabarits du dossier `templates/` et la feuille de style de `static/css/` pour construire l’application. Les blocs provisoires visibles indiquent où afficher les listes de tâches, les tâches, les attributions et les échanges réels.

Les gabarits utilisent la syntaxe Django (`{% extends %}`, `{% block %}` et `{% static %}`). Dans un projet Django, ajoutez `templates/` aux chemins de recherche des gabarits et configurez les fichiers statiques pour servir `static/css/style.css`. Remplacez chaque marqueur `TODO` au fur et à mesure que vous réalisez la fonctionnalité correspondante.
